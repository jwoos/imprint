# Imprint Configuration
Wireless Cyboard keyboard configuration repository template for using ZMK firmware. [Instructions for use are located on our documentation site](https://docs.cyboard.digital/user-manual/quick-start/configure-layout).

This uses ZMK.


## Editor
Web based GUI editor to make life a little easier: https://nickcoutsos.github.io/keymap-editor/

## Build References
- https://github.com/zmkfirmware/zmk
- https://github.com/Cyboard-DigitalTailor/zmk-keyboards

These are referenced in `west.yml`

The Github build workflow is just the one in zmk.
